 Blue365 통합 품질관리 시스템(QMS) — 사내망(오프라인) 설치 안내
 패키지 {VERSION} · Windows 10/11 64비트 · 인터넷 연결 불필요
====================================================================

이 패키지에는 실행에 필요한 것이 모두 들어 있습니다.
  · 프로그램(Blue365 QMS)
  · Python {PY_VERSION} — 휴대용(PC에 설치하지 않음, 관리자 권한 불필요)
  · 구성요소 라이브러리 {N_PKGS}종 — Streamlit {STREAMLIT}, pandas, numpy, scipy, plotly 등(미리 설치됨)
  · 더블클릭용 설치·실행 파일(.bat)


1. 받은 파일
--------------------------------------------------------------------
{PARTS_TABLE}
  ※ 크기와 SHA-256 값이 위와 같아야 정상입니다(전송 중 손상 여부 확인용).
  ※ 사내 자료전송 시스템의 용량 제한에 맞추려고 나눴습니다. 같은 폴더에만 두면
    1_SETUP.bat 이 자동으로 확인하고 합칩니다(따로 압축을 풀 필요 없음).


2. 설치 (최초 1회, 약 5~15분)
--------------------------------------------------------------------
  ① 받은 ZIP 파일 {N}개를 사내망 PC의 같은 폴더(예: 다운로드)에 둡니다.
  ② (인터넷에서 받은 파일이면) 각 ZIP 파일 → 마우스 오른쪽 → 속성 → 아래쪽 '차단 해제' 체크 → 확인.
     실행할 때마다 나오는 보안 경고를 막아 줍니다.
  ③ 1of{N} ZIP 파일만 압축을 풉니다: 마우스 오른쪽 → '압축 풀기...' → 위치를 C:\ 로 지정
     → C:\Blue365_QMS 폴더가 생깁니다.
     (경로가 짧을수록 좋습니다. 바탕화면·OneDrive 폴더는 피하세요.)
  ④ 나머지 ZIP 파일(2of{N} …)을 C:\Blue365_QMS 폴더에 복사합니다.
     (다운로드 폴더에 그대로 두어도 자동으로 찾습니다.)
  ⑤ C:\Blue365_QMS\1_SETUP.bat 을 더블클릭합니다.
     - 보안 경고('Windows의 PC 보호' 등)가 뜨면 [추가 정보] → [실행]을 누르세요.
     - 분할 파일 결합 → 컴파일 → 구성요소 점검 → 화면 자체 시험 순서로 진행됩니다.
     - '설치가 끝났습니다'가 나오면 완료입니다. 설치 기록은 logs 폴더에 남습니다.


3. 실행
--------------------------------------------------------------------
  · 내 PC에서만 보기 : 2_RUN.bat → 브라우저가 자동으로 열립니다(http://localhost:8501).
  · 다른 PC에서도 보기(사내망 공유) : 3_RUN_SHARE.bat → 검은 창에 표시된 주소
    (예: http://10.1.2.3:8501)를 다른 PC의 브라우저(Edge·Chrome)에 입력합니다.
    처음 1회는 4항의 방화벽 허용이 필요하고, 6항의 접속 비밀번호 설정을 권장합니다.
  · 검은 실행 창을 닫으면 프로그램이 종료됩니다. 사용하는 동안에는 최소화해 두세요.
  · 바탕화면 바로가기: 2_RUN.bat → 마우스 오른쪽 → 보내기 → 바탕 화면에 바로 가기 만들기
  · 처음에는 데모 데이터(가상 120일 품질 데이터)로 시작합니다. 실제 데이터는
    [📥 데이터 관리] 화면에서 엑셀 템플릿으로 올리거나 [🔗 LIMS 연동]으로 가져옵니다.
  · Internet Explorer는 지원하지 않습니다. Edge 또는 Chrome을 사용하세요.


4. 사내망 공유 — 방화벽 허용 (공유하는 PC에서 1회, 관리자 권한)
--------------------------------------------------------------------
  · 4_FIREWALL_ADMIN.bat → 마우스 오른쪽 → '관리자 권한으로 실행'.
  · 관리자 권한이 없으면 IT 담당자에게 요청하세요.
      - 인바운드 허용: TCP 8501 (도메인·개인 프로필)
      - 프로그램: C:\Blue365_QMS\py\python.exe
  · 3_RUN_SHARE.bat 을 처음 실행할 때 'Windows 보안 경고(방화벽)' 창이 뜨면 [액세스 허용]을 누르세요.
    [취소]를 누르면 차단 규칙이 생기는데, 4_FIREWALL_ADMIN.bat 을 실행하면 정리됩니다.
  · 다른 PC에서 화면이 '연결 중…'에서 멈추면 그 PC 브라우저의 프록시 설정 때문일 수 있습니다.
    IT에 '공유 PC의 사내 IP는 프록시를 거치지 않도록 예외 등록'을 요청하세요.


5. 자동 감시·알림 (선택)
--------------------------------------------------------------------
  · 5_MONITOR_TASK.bat → 1번: 30분마다 LIMS 동기화 → 이상 감지 → 알림(메일·메신저 웹훅)을 실행합니다.
  · 프로그램 화면을 열어 두지 않아도 되지만, 이 PC에 로그인해 있어야 합니다.
  · 알림 기준·채널은 [⚙️ 기준·알림 설정], LIMS 접속은 [🔗 LIMS 연동] 화면에서 설정합니다.
  · 실행 기록: C:\Blue365_QMS\logs\monitor.log  (5_MONITOR_TASK.bat → 4번으로도 확인)


6. 비밀번호·접속 설정 (secrets.toml)
--------------------------------------------------------------------
  메일·LIMS 비밀번호, 접속 비밀번호, AI 키는 화면에 저장하지 않고 아래 파일에 둡니다.
  · C:\Blue365_QMS\app\.streamlit\secrets.toml.example 을 같은 폴더에 secrets.toml 로 복사한 뒤
    메모장으로 편집하고 'UTF-8'로 저장합니다.
  · [access] password = "비밀번호"  → 사내망 공유 시 접속 비밀번호(권장).
    비워 두면 사내망의 누구나 접속해 기준·설정을 바꿀 수 있습니다.
  · 수정한 뒤에는 실행 창을 닫고 다시 실행하세요.
  ※ 이 파일은 백업(6_BACKUP.bat)에 넣지 않습니다. 따로 안전하게 보관하세요.


7. 데이터 위치·백업·업데이트·제거
--------------------------------------------------------------------
  · 데이터: C:\Blue365_QMS\data (품질 DB qms.db, 사용자 기준·알림·LIMS 설정 파일)
  · 백업: 6_BACKUP.bat → C:\Blue365_QMS\backups\QMS_data_날짜_시각.zip (실행 중에도 가능)
  · 새 버전으로 업데이트
      ① 6_BACKUP.bat 으로 백업하고 실행 창을 모두 닫습니다.
      ② 기존 폴더 이름을 바꿉니다(예: C:\Blue365_QMS_old).
      ③ 새 패키지를 2항 순서대로 설치합니다.
      ④ 옛 폴더의 data 폴더와 app\.streamlit\secrets.toml 을 새 폴더의 같은 위치에 복사합니다.
      ⑤ 5_MONITOR_TASK.bat 을 썼다면 1번(등록)을 한 번 더 실행합니다.
  · 제거: 5_MONITOR_TASK.bat → 2번(해제) → (공유했다면) 관리자 명령 프롬프트에서
      netsh advfirewall firewall delete rule name=Blue365_QMS_TCP8501
      netsh advfirewall firewall delete rule name=Blue365_QMS_python
    → C:\Blue365_QMS 폴더 삭제. Python을 PC에 설치하지 않았으므로 폴더만 지우면 됩니다.


8. 문제 해결
--------------------------------------------------------------------
  · 9_CHECK.bat: 설치 상태·구성요소·포트·IP·방화벽·설정을 점검해 logs\check_날짜.txt 로 저장합니다.
    문의할 때 이 파일을 함께 보내 주세요(비밀번호 값은 기록하지 않습니다).
  · 'py\python.exe 파일이 없습니다' → ZIP 안에서 바로 실행한 경우입니다. 압축을 모두 푼 뒤 실행하세요.
  · '파일을 찾을 수 없음' 또는 '손상' → 2of{N} … ZIP 파일을 C:\Blue365_QMS 에 복사하세요.
    크기·SHA-256이 1항과 다르면 다시 받으세요.
  · '설치 경로가 깁니다' → 폴더를 C:\Blue365_QMS 로 옮기세요(Windows 경로 260자 제한).
  · 백신·보안 프로그램이 실행을 막는 경우 → IT에 C:\Blue365_QMS\py\python.exe, pythonw.exe
    예외 등록을 요청하세요(Python Software Foundation 디지털 서명 파일).
  · 포트 8501을 다른 프로그램이 쓰고 있으면 8502 등 빈 포트로 자동 실행됩니다(검은 창의 주소 확인).
  · 브라우저가 자동으로 열리지 않으면 직접 http://localhost:8501 을 입력하세요.
