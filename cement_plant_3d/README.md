# 시멘트 공정 3D 모니터링 (Blue365)

석회석 광산부터 출하까지 전체 공정을 3D 지도로 보여 주는 모니터링·경영진 보고 화면입니다.
**모든 수치는 시연용 가상 데이터**입니다. 실제 DCS·LIMS와는 아직 연결되어 있지 않습니다.

## 파일
| 파일 | 용도 |
|---|---|
| `cement_plant_3d.html` | **사내망(오프라인)용 완성본.** three.js가 파일 안에 들어 있어 더블클릭으로 바로 열립니다. |
| `src.html` | 편집용 원본 (three.js를 CDN에서 불러옴) |
| `build.py` | `src.html` → `cement_plant_3d.html` 오프라인 빌드 (`python cement_plant_3d/build.py`) |
| `vendor/three.min.js` | three.js r149 (MIT, `vendor/three.LICENSE`) |

## 화면
- **공정 지도**: 마우스 왼쪽 끌기 = 이동, 휠 = 확대/축소, 오른쪽 끌기(또는 Shift+끌기) = 회전. 휴대폰은 한 손가락 이동, 두 손가락 확대·회전.
  설비·트럭을 누르면 오른쪽 상세 패널(관리기준 대비 상태, 최근 추이, 클링커 LSF·SM·IM·Bogue 광물)이 열립니다.
- **경영진 요약**: 결론형 제목, 생산 실적, 모듈 관리, f-CaO 관리도, 출하·사일로, KS L 5201 대비 평가, 확인 필요 알람.
- **알람**: 관리기준 근접(주의)·이탈 기록, 확인 처리, 지도에서 보기.

## 기준값 출처와 주의
- KS 기준값은 KS L 5201(포틀랜드 시멘트) 1종 기준으로 적었습니다. **최신 개정판 원문과 대조 후 사용**하세요(특히 강열감량).
- 사내 관리기준, 28일 강도 예측식은 **가상값**입니다. 실제 적용 시 공장 데이터로 교체·보정해야 합니다.
- LSF·SM·IM·C₃S 계산식은 일반적인 정의(Bogue 식)를 사용했습니다.
