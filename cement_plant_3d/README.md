# 시멘트 공정 3D 모니터링 (Blue365)

석회석 광산부터 출하까지 전체 공정을 3D 지도로 보여 주는 모니터링·경영진 보고 화면입니다.
공장 1곳, 킬른 5기(3·4·5·6·7호)를 기준으로 합니다. 공정 지도는 **탭**으로 나뉩니다.

| 탭 | 설비 |
|---|---|
| 전체 공장 | 모든 설비 + 석회석 광산·크러셔·프리블렌딩·품질관리실 |
| 3–5호 킬른 | 원료밀 3·4·5·5-1호 R/M(3호 가동 중지, 5-1호 → 5호 원료 사일로), 원료 사일로 3·4·5호, 예열기 3·4·5호 P/H, 킬른 3·4·5호, 클링커 사일로 2·4·5호 |
| 6–7호 킬른 | 원료밀 6·7호 R/M, 원료 사일로 6-1·6-2·7-1·7-2호, 예열기 6·7호 P/H, 킬른 6·7호, 클링커 사일로 6-1~6-6호 (6-4·6-6호는 3종 시멘트용·수출 클링커 겸용으로 별도 관리) |
| 시멘트 밀·사일로 | 시멘트 밀 2~7호 C/M, 시멘트 사일로 1·2·5~11호, 4호 사일로(F/A 플라이애시), 출하장 |

시멘트 밀 경로: 2~6호 C/M은 모든 킬른 클링커, 7호 C/M은 6·7호 킬른 클링커만 사용합니다. 2~4호 C/M → 주로 1종 5~9호 사일로(3종 생산 시 9호), 5호 C/M → 3종 1호·1종 2호, 6호 C/M → 1종 8호·S/C2종 10호·S/C3종 11호, 7호 C/M → 1종 5~7호. 4호 사일로의 F/A는 혼합재로 시멘트 밀에 투입합니다.
이 경로 정보는 `src.html`의 `ROUTE`에서 고칠 수 있습니다. C/M별 현재 생산 품종(`CUR`)은 가상 예시입니다.
호기별 설계 용량은 3호 2,200, 4호 3,120, 5호 3,120, 6호 7,600, 7호 7,600 t/d(합계 23,640 t/d)입니다. **3호는 가동 중단** 상태로 표시하며, 공장 합계 생산 목표·평균 f-CaO·모듈 평균·알람 판정에서 뺍니다(가동 4기 설계 21,440 t/d 기준).
호기별 클링커 생산은 원료 투입량 × 24 ÷ 원료/클링커 환산계수 **1.55**로 추정합니다.
용량·환산계수·가동 중단 설정을 바꾸려면 `src.html`의 `KILN_DEF`·`CLK_FACTOR`와 `make_template.py`의 `KILNS`·`STOPPED`·`CLK_FACTOR`를 고친 뒤 `build.py`, `make_template.py`를 다시 실행하세요.
업로드 데이터에서는 원료 투입량(feed)이 1 t/h 이하인 호기를 가동 중단으로 판단합니다. 투입량 값이 없으면 위 설정을 따릅니다.
분석값은 **QMS 데이터**(LIMS 원본 형식 엑셀), 설비 운전값은 **가상**입니다.

- 선박 상태는 **지금 시각**과 속보의 시각으로 계산합니다. 속보에 없는 것은 추정입니다: 완료 시각이 없으면 양하지 칸의 ‘07시’, 출항 시각이 없으면 같은 선석 다음 입항 30분 전(없으면 완료 + 12시간), T/H가 없으면 24시 선적량으로 계산 — 화면에 ‘(추정)’으로 표시.
- **D-1 알림**: 동해항 입항·출항(출항 예정은 속보에 ‘(11/25 출.예)’나 출항 시각이 나오면 자동 적용), 삼척항 입항 예정 선박 — 하루 전(과 당일)에 알람 목록에 올라가고, 토스트는 하루 한 번(삼척항은 날짜별로 묶어서) 보여 줍니다.
- 부두 모양·거리와 선석의 좌우 위치는 추정입니다(선석 번호·능력·연결 관계는 현장 제공).

## 원료 공급 공정 (현장 제공 구성)
- 3D 배치 순서: 화면 앞쪽부터 **3→4→5→6→7호**. OSP·P/W·프리블렌딩(Y1 앞)·원료밀·원료 사일로·예열기·킬른·쿨러·클링커 사일로가 같은 순서로 놓입니다(`src.html`의 `MZ`). 광산·크러셔·시멘트 밀·출하장 배치는 그대로입니다.
- 클링커 벨트: 3·4·5호 쿨러 → 앞의 2·4·5호 클링커 사일로로 각각. 6·7호 쿨러 → 모음 벨트 → 6-1~6-3(앞줄)·6-4~6-6(뒷줄) 위 분배 벨트(어느 사일로에나 투입).
  사일로 아래 인출 벨트 2줄(3~5K → 2~6호 C/M, 6-7K → 2~7호 C/M)이 시멘트 밀 위 투입 벨트로 이어집니다.
- 예열기 굴뚝은 예열기와 원료 사일로 사이에 있습니다.
- 광산 발파(연출): 매 분 정각부터 **10초 카운트다운**(광산 위 숫자 칩, 마지막 3초는 빨강, 광산 이름표에 ‘발파 N초 전’) 뒤 **49Q·47Q·45Q가 동시에** 발파합니다(섬광·비석·충격파·분진, 모든 화면 같은 때). 카운트다운부터 분진 확인(발파 후 9초)까지 덤프트럭은 ‘발파 대기’로 멈추고, 그 뒤 석회석을 크러셔로 다시 운반합니다. 움직임 줄이기 설정에서는 폭발 효과 없이 카운트다운과 트럭 정지만 합니다.
석회석 광산 **49Q · 47Q · 45Q** → 크러셔 **G/C (Gyratory, 1차) → C/C 1·2호 (Cone Crusher, 2차)** · **H/C (Hammer, 단독)** → **OSP**에서 라인 분리 → **P/W (Paddle Wheel)** 인출

| 설비 (현장 제공 2026-11-12) | 설계 용량 |
|---|---|
| G/C (1차 크러셔) | 1,500 t/h |
| C/C (Cone Crusher, 2차) 2기 | 각 1,000 t/h |
| H/C (단독) | 1,500 t/h |
| 광산(크러셔) → OSP 이송 벨트 | 1,400 t/h |
| OSP → 프리블렌딩 이송 벨트 | 기존 1,100 t/h · 신설 1,150 t/h |
| OSP 기존 · 신설 | 각 40,000 t |
| P/W 1~4호 | 각 1,500 t/h |
| 프리블렌딩 기존 (Y1·Y2) | 설계 35,000 t · **운영 37,000 t** |
| 프리블렌딩 신설 (Y1·Y2) | 설계 40,000 t · **운영 50,000 t** |

- 프리블렌딩 저장률(%)은 **운영 용량** 기준이며, 상세 화면에 설계 대비 운영 비율(기존 106%, 신설 125%)을 함께 보여 줍니다.
- 관리 상한: OSP 입고량 1,400 t/h, OSP 인출량(P/W 합계)·야드 처리량은 라인별 이송 벨트(기존 1,100 · 신설 1,150 t/h), P/W·크러셔는 각 설계 용량입니다.
| 라인 | OSP | 인출 | 프리블렌딩 야드 | 원료밀 |
|---|---|---|---|---|
| 3~5호 Line (기존) | OSP (기존) | P/W 1·2호 | 기존 Y1 · Y2 | 3·4·5·5-1호 R/M |
| 6~7호 Line (신설) | OSP (신설) | P/W 3·4호 | 신설 Y1 · Y2 | 6·7호 R/M |

- 프리블렌딩 야드는 라인마다 한 야드는 **적재(Stacking)**, 다른 야드는 **사용(Reclaiming)**입니다. 화면에서 사용 야드가 거의 비면(4% 이하) 두 야드의 역할이 자동으로 바뀝니다(가상 시뮬레이션).
- 킬른 가동 표시: 가동 중이면 P/H 꼭대기 알람등이 켜지고(정지 시 꺼짐) 킬른 쉘이 버너 쪽부터 붉게 달아오른 모습으로 보입니다. 굴뚝 연기도 가동 중에만 나옵니다.
- 설계 용량은 현장 제공값이고, 광산→크러셔 운반 배정·부하·저장량·처리량 같은 운전값은 가상값입니다.

## 경영진 요약 내려받기 (PPT · 엑셀)
경영진 요약 화면 오른쪽 위의 **PPT 내려받기 / 엑셀 내려받기**를 누르면 선택한 기간 기준으로 파일을 만듭니다(외부 프로그램·인터넷 불필요, 모든 권한 사용 가능).
- **PPT (9장)**: 표지 → 핵심 요약(카드 5개·핵심 내용) → 호기별 현황 → 클링커 생산 추이 → f-CaO 관리도 → 1종 KS 평가 → 3종 KS 평가 → 28일 강도 추이 → 근거·기준
- **엑셀 (6개 시트)**: 요약 · 호기별 · 일별(생산·f-CaO) · 출하 로트 · KS 평가 · 기준·근거
- 가상값(생산·가동률)과 추정 KS 기준(*)은 파일 안에도 그대로 표시됩니다.

## 관리기준 설정
오른쪽 위 **톱니 아이콘**에서 바꿉니다(팀 공유 서버에서는 관리자만, 저장하면 모든 화면에 20초 안에 반영, `data/settings.json`).
- 클링커 f-CaO: 목표, 허용폭(±), ‘주의’로 보는 일평균 이탈 비율
- 출하 시멘트(1종·3종): 항목별 KS 기준값과 **확인** 표시, 사내 하한·상한
- **킬른·원료밀 정지·보수 기간**: 설비(3~7호 킬른, 3·4·5·5-1·6·7호 R/M)·시작일·종료일(비우면 ‘지금까지’)·구분(가동 중단/보수)·메모. 기본값(현장 확인 2026-11-12):

  | 설비 | 기간 | 구분 |
  |---|---|---|
  | 3호 킬른 · 3호 R/M | 전 기간 | 가동 중단 |
  | 4호 킬른 | 2025-04-05 ~ 2025-12-13, 2026-07-24 ~ | 가동 중단 |
  | 4호 R/M | 2025-04-05 ~ 2025-12-13, 2026-07-23 ~ | 가동 중단 |
  | 5호 킬른 | 2025-06-08 ~ 06-27, 2025-09-09 ~ 10-01, 2026-02-18 ~ 03-10, 2026-07-04 ~ 09-10 | 보수 |
  | 5호 R/M | 2025-06-07 ~ 06-27, 2025-09-08 ~ 10-02 | 가동 중단 |
  | 5-1호 R/M | 2025-06-08 ~ 06-27, 2025-09-08 ~ 10-01 | 가동 중단 |

  - *가동 중단* 기간은 달력시간에서 빼므로 가동률·설계용량에 들어가지 않습니다(그 설비는 ‘정지’로 표시).
  - *가동 중단* 기간에 들어온 **분석 시료는 입력 오류로 보고 업로드할 때 제외**하고, 불러오기 결과에 시트·행 번호로 알려 줍니다(운전값 DCS는 그대로). 기간을 바꾼 뒤에는 파일을 다시 올려야 반영됩니다.
  - *보수* 기간은 달력시간에 넣고 정지 시간으로 셉니다(가동률이 내려감).
  - DCS 투입량 값이 있는 날은 DCS 값이 우선입니다.
  - 기본 기간이 늘어나면 예전에 저장한 설정에도 빠진 기본 기간만 덧붙입니다(직접 넣은 기간은 그대로).
- KS 값은 KS L 5201 원문과 대조한 뒤 ‘확인’에 표시하세요. 확인하지 않은 값은 화면·PPT에 `*`(추정)로 나오고, 그 기준을 벗어난 로트는 ‘미달’이 아니라 ‘추정 기준 밖’으로 표시합니다.
- 경영진 요약 09번 표는 선택 기간의 출하 로트를 항목별로 평가합니다(평균·범위·로트 수·KS 미달 건수·사내 범위 밖 건수).

## 기간 (일 평균 · 월 평균 · 년 평균 · 기간 지정)
공정 지도와 경영진 요약의 기간 바에서 **일 / 월 / 년 평균 · 기간 지정**을 고르면 카드와 보고서(생산 막대, 클링커 모듈, f-CaO 관리도, 출하 강도 추이)가 모두 같은 기간으로 계산됩니다. 두 화면은 기간을 공유하며, 화면을 열면 **당월**로 시작합니다.

| 카드 | 계산 |
|---|---|
| 클링커 생산 | 기간 내 하루 생산량(원료 투입량 × 24 ÷ 1.55)의 평균 t/d. DCS 일평균이 있으면 DCS, 없으면 가상 |
| 킬른 가동률 | (달력시간 − 정지시간) ÷ 달력시간. 관리기준 설정의 ‘가동 중단’ 기간은 달력시간에서 제외, ‘보수’ 기간은 정지시간으로 셈. DCS 없으면 가상 |
| f-CaO | QMS 클링커 호기별 일평균의 기간 평균(공장은 설계용량 가중), 관리기준 0.7~1.7% 이탈 횟수 |
| 1종·3종 출하 | 기간 내 출하 로트(채취일 기준) 값의 평균, 로트 수와 KS 미달 건수 |

- 원료밀·사일로 재고·금일 출하 등 설비 상태 카드는 '현재' 값입니다.
- 현재 기간(오늘·당월·올해)을 보고 있으면 자정·월말이 지날 때 자동으로 새 기간으로 넘어갑니다(화면을 계속 켜 두는 경우). 과거 기간을 보는 중에는 그대로 둡니다.
- 킬른(DCS) 시트의 0은 실제 값(정지)으로 읽습니다. 분석 시트의 0·빈칸은 미시험으로 봅니다.
- 28일 강도는 채취 28일 뒤에 나오므로 당월 로트에는 아직 값이 없을 수 있습니다.

## 데이터 구성
| 구분 | 출처 | 비고 |
|---|---|---|
| **분석값** (원료 XRF·LSF·SM·IM·잔사, 클링커 XRF·f-CaO, 시멘트 Blaine·45㎛·SO₃, 출하 시멘트 물성·강도, 인수검사) | **QMS 통합 업로드 양식** (`업로드양식.xlsx`, LIMS 원본 형식) | 화면에 기본으로 `Blue365_QMS.xlsx`(2025-01-01~2026-10-31)를 넣어 두었습니다 (`qms_default.json`) |
| **설비 운전값** (생산량·부하·온도·레벨·차량·로트) | 가상 | 양식의 ‘킬른’ 시트(DCS)를 채우면 킬른·예열기 운전값은 그 값으로 바뀝니다 |

- 분석 항목의 관리한계는 최근 90일 QMS 데이터의 **평균±3σ**로 자동 계산합니다(시멘트는 C/M·품종별). f-CaO는 사내 관리기준 **1.2 ± 0.5%(0.7~1.7%)**를 씁니다 (`src.html`의 `FCAO_TARGET`·`FCAO_TOL`).
- 최근 14일 시료가 없는 분석 항목은 ‘—’와 ‘마지막 시료 날짜’로 표시하고 상태 판정에서 뺍니다.
- C/M ‘현재 생산’은 시멘트 시트의 C/M별 마지막 시료(품명·투입사일로)이며, 경로표(`ROUTE`)와 다르면 ‘경로표와 다름’으로 표시합니다.
- 시멘트 시트의 Blaine·45㎛ 값이 LIMS 내려받기에서 서로 바뀌어 있으면(Blaine < 100, 45㎛ > 1000) 자동으로 바로잡습니다.
- 미래 날짜 행은 날짜 오류로 보고 제외합니다.

## 2단계 · 팀 공유 (사내 PC 한 대를 서버로)
1. 그 PC에 **Python 3.8 이상**이 있으면 됩니다(추가 설치·인터넷 불필요).
2. `cement_plant_3d` 폴더를 복사하고 `서버실행.bat`(또는 `python server.py`)을 실행합니다. 처음 실행 시 Windows 방화벽에서 포트 8365를 허용하세요.
3. 팀원은 서버 창에 표시되는 **IP 주소**(예: `http://192.168.0.15:8365`)로 접속합니다. 컴퓨터 이름에 한글이 있으면 이름 주소는 동작하지 않습니다(브라우저가 `xn--…`로 바꿔 ‘잘못된 URL’이 뜸). IP는 `ipconfig`의 IPv4 주소로도 확인할 수 있고, 데이터 창에도 표시됩니다. 누군가 **팀에 공유하고 적용**을 누르면 모든 접속자 화면에 20초 안에 반영됩니다(서버에는 집계 결과만 저장).
4. `--watch "\\서버\품질\QMS"`를 붙이면 그 폴더에 저장된 최신 QMS 엑셀을 자동으로 반영합니다(매일 LIMS 내려받기 → 폴더 저장 운영).

| 서버 옵션 | 설명 |
|---|---|
| `--port 8365` | 포트 번호 |
| `--allow 대역` | 접속 허용 대역 (예: `192.168.10.0/24` 또는 `192.168.10.`, 쉼표로 여러 개). **지정하지 않아도 사내망 사설 IP(10.x, 172.16~31.x, 192.168.x)만 허용**하고 인터넷(공인 IP)에서 온 접속은 거절합니다 |
| `--allow-any` | 접속 대역 제한 끄기 (권장하지 않음) |
| `--key 암호` | (선택) 서버 공통 업로드 암호를 하나 더 겁니다. 기본은 ‘편집 권한 + 본인 비밀번호 재확인’ |
| `--watch 폴더` | 공유 폴더의 최신 `.xlsx` 자동 반영 (`--interval` 초, 기본 60) |
| `--history-mb 1024` | 이력(data/history) 최대 용량 MB. 넘으면 오래된 것부터 지움(최근 5개는 보관) |
| `--backup-dir 폴더` | 자동 백업 위치 (기본 `data/backup`). **다른 디스크·공유 폴더를 권장** |
| `--backup-keep 14` | 보관할 백업 개수 (하루 1개) |
| `--no-backup` | 자동 백업 끄기 |
| `--data 폴더` | 저장 위치 (기본 `data/`, 최근 200건 이력) |

- 기본으로 사내망 사설 IP에서 온 접속만 받고, **로그인한 승인 사용자만** 화면·데이터를 볼 수 있습니다.
- 연결은 HTTP(암호화 안 됨)입니다. 사내망 전용으로만 쓰세요.

### 로그인 · ID 등록 · 승인
1. **관리자 만들기 (처음 한 번)**: 서버 PC의 브라우저에서 `http://localhost:8365`로 접속하면 ‘관리자 계정 만들기’ 화면이 나옵니다. 다른 PC에서는 만들 수 없습니다.

4. **권한**

| 권한 | 할 수 있는 일 |
|---|---|
| 뷰어 | 공정 화면·경영진 요약 보기, 업로드 양식 받기 |

- **로그인 유지**: 뷰어·편집은 화면을 켜 둔 동안 계속 유지됩니다(화면을 닫고 12시간이 지나면 종료). 관리자는 로그인 뒤 12시간까지만 유지됩니다. 서버를 다시 켜도 로그인은 유지됩니다(`data/sessions.json`, 토큰 원문은 저장하지 않음). 권한을 바꾸거나 사용 중지하면 그 사용자는 바로 로그아웃됩니다.
- **상황판(계속 띄워 두는 화면)** 은 관리자 계정이 아닌 **뷰어 전용 계정**(예: 부서 ‘상황실’, 이름 ‘모니터’)을 만들어 로그인해 두세요.

- 사용자 목록은 `data/users.json`, 기록은 `data/audit.log`입니다. 서버가 **하루 한 번 자동 백업**(`blue365-backup-날짜.zip`: 사용자·관리기준·최신 데이터·감사 기록)을 만듭니다. 복구할 때는 서버를 끄고 zip 안의 파일을 `data/` 폴더에 풀어 넣으면 됩니다. 백업에는 비밀번호 변환값이 들어 있으니 접근 권한이 있는 폴더에 두세요. 관리자 비밀번호를 잊었다면 서버를 끄고 `users.json`에서 관리자 항목을 지운 뒤 다시 켜면 localhost에서 새로 만들 수 있습니다.
- `cement_plant_3d.html` 파일을 직접 열면(file://) 로그인 없이 내장 데이터로 열립니다. 이 파일은 서버 PC·공유 폴더에서 아무나 가져가지 못하게 보관하세요.
- 8365 포트를 공유기·방화벽에서 외부로 열지 마세요. Windows 방화벽은 ‘도메인/개인’ 네트워크만 허용하세요.

| 공정구분 · 항목사전 · 사용법 | 목록 선택 코드표 · 열 설명 · 사용법 | — |

- 시트는 **이름이 아니라 3행 머리글로** 알아봅니다(시트 이름·열 순서 변경 가능, 안 쓰는 열 삭제 가능).
- 공정구분 코드: 킬른 `3K~7K`, 원료밀 `3R/M·4R/M·5R/M·5-1R/M(5_1R/M)·6R/M·7R/M`, 시멘트밀 `2C/M~7C/M`. 클링커 투입사일로 `2호·4호·5호·6-1호~6-6호`, 시멘트 투입사일로 `구내1·2·5~11호·부두1·2호`.
- **분석값의 0 또는 빈 칸 = 미시험**(결과가 아직 안 나왔거나 시험하지 않음), **음수 = 무효**(검출한계 아래 등)로 보고 평균·판정에서 뺍니다. 운전값(킬른·시멘트 DCS)의 0은 실제 값(정지)입니다.
- LSF·SM·IM·C₃S·C₂S·C₃A·C₄AF는 **LIMS 계산값을 그대로** 씁니다. 그 열이 없으면 같은 식으로 계산합니다: C₃S = 4.071CaO − 7.600SiO₂ − 6.718Al₂O₃ − 1.430Fe₂O₃ (SO₃·f-CaO 보정 없음, LIMS와 같은 식).
- **C₃S와 mC₃S를 함께 봅니다.** mC₃S = C₃S − 4.071 × f-CaO (반응하지 않은 자유석회만큼 뺀 값, LIMS 값이 있으면 그대로). 지도 화학 칩·호기별 표·모듈 표·PPT·엑셀에 둘 다 나옵니다.
- 시멘트밀 시트의 품종은 **시멘트구분을 우선**으로 판단합니다(내수 = 1종, 3종, S/C2종, S/C3종). 시멘트구분이 비어 있을 때만 품명을 봅니다. 표기는 띄어쓰기 없이 `S/C2종`·`S/C3종`으로 씁니다(‘S/C 2종’도 같은 것으로 읽음).
- 공정구분 `SA1KL3`·`SA1KL6` 같은 LIMS 입력 오류 코드는 읽지 않고 불러오기 결과에 따로 행 수를 알려 줍니다.
- 앞뒤 행과 60일 넘게 동떨어진 날짜(오타로 보이는 날짜)는 불러오기 결과에 행 번호와 함께 알려 줍니다. 미래 날짜는 읽지 않습니다.
