# 시멘트 공정 3D 모니터링 (Blue365)

석회석 광산부터 출하까지 전체 공정을 3D 지도로 보여 주는 모니터링·경영진 보고 화면입니다.
공장 1곳, 킬른 5기(3·4·5·6·7호)를 기준으로 합니다. 공정 지도는 **탭**으로 나뉩니다.

| 탭 | 설비 |
|---|---|
| 전체 공장 | 모든 설비 + 석회석 광산·크러셔·프리블렌딩·품질관리실 |
| 3–5호 킬른 | 원료밀 3·4·5·5-1호 R/M(3호 가동 중지, 5-1호 → 5호 원료 사일로), 원료 사일로 3·4·5호, 예열기 3·4·5호 P/H, 킬른 3·4·5호, 클링커 사일로 2·4·5호 |
| 6–7호 킬른 | 원료밀 6·7호 R/M, 원료 사일로 6-1·6-2·7-1·7-2호, 예열기 6·7호 P/H, 킬른 6·7호, 클링커 사일로 6-1~6-6호 (6-4·6-6호는 3종 시멘트용·수출 클링커 겸용으로 별도 관리) |
| 시멘트 밀·사일로 | 시멘트 밀 2~7호 C/M, 시멘트 사일로 1·2·5~11호, 4호 사일로(F/A 플라이애시), 출하장 |

시멘트 밀 경로: 2~6호 C/M은 모든 킬른 클링커, 7호 C/M은 6·7호 킬른 클링커만 사용합니다. 2~4호 C/M → 주로 1종 5~9호 사일로(3종 생산 시 9호), 5호 C/M → 3종 1호·1종 2호, 6호 C/M → 1종 8호·S/C 2종 10호·S/C 3종 11호, 7호 C/M → 1종 5~7호. 4호 사일로의 F/A는 혼합재로 시멘트 밀에 투입합니다.
이 경로 정보는 `src.html`의 `ROUTE`에서 고칠 수 있습니다. C/M별 현재 생산 품종(`CUR`)은 가상 예시입니다.
호기별 설계 용량은 3호 2,200, 4호 3,120, 5호 3,120, 6호 7,600, 7호 7,600 t/d(합계 23,640 t/d)입니다. **3호는 가동 중단** 상태로 표시하며, 공장 합계 생산 목표·평균 f-CaO·모듈 평균·알람 판정에서 뺍니다(가동 4기 설계 21,440 t/d 기준).
호기별 클링커 생산은 원료 투입량 × 24 ÷ 원료/클링커 환산계수 **1.55**로 추정합니다.
용량·환산계수·가동 중단 설정을 바꾸려면 `src.html`의 `KILN_DEF`·`CLK_FACTOR`와 `make_template.py`의 `KILNS`·`STOPPED`·`CLK_FACTOR`를 고친 뒤 `build.py`, `make_template.py`를 다시 실행하세요.
업로드 데이터에서는 원료 투입량(feed)이 1 t/h 이하인 호기를 가동 중단으로 판단합니다. 투입량 값이 없으면 위 설정을 따릅니다.
분석값은 **QMS 데이터**(LIMS 원본 형식 엑셀), 설비 운전값은 **가상**입니다.

## 원료 공급 공정 (현장 제공 구성)
석회석 광산 **49Q · 47Q · 45Q** → 크러셔 **G/C (Gyratory Crusher) · H/C (Hammer Crusher)** → **OSP**에서 라인 분리 → **P/W (Paddle Wheel)** 인출
| 라인 | OSP | 인출 | 프리블렌딩 야드 | 원료밀 |
|---|---|---|---|---|
| 3~5호 Line (기존) | OSP (기존) | P/W 1·2호 | 기존 Y1 · Y2 | 3·4·5·5-1호 R/M |
| 6~7호 Line (신설) | OSP (신설) | P/W 3·4호 | 신설 Y1 · Y2 | 6·7호 R/M |

- 프리블렌딩 야드는 라인마다 한 야드는 **적재(Stacking)**, 다른 야드는 **사용(Reclaiming)**입니다. 화면에서 사용 야드가 거의 비면(4% 이하) 두 야드의 역할이 자동으로 바뀝니다(가상 시뮬레이션).
- 킬른 가동 표시: 가동 중이면 P/H 꼭대기 알람등이 켜지고(정지 시 꺼짐) 킬른 쉘이 버너 쪽부터 붉게 달아오른 모습으로 보입니다. 굴뚝 연기도 가동 중에만 나옵니다.
- 광산→크러셔 운반 배정, 용량, 저장량, 처리량은 가상값입니다.

## 기간 (일 평균 · 월 평균 · 년 평균 · 기간 지정)
공정 지도와 경영진 요약의 기간 바에서 **일 / 월 / 년 평균 · 기간 지정**을 고르면 카드와 보고서(생산 막대, 클링커 모듈, f-CaO 관리도, 출하 강도 추이)가 모두 같은 기간으로 계산됩니다. 두 화면은 기간을 공유하며, 화면을 열면 **당월**로 시작합니다.

| 카드 | 계산 |
|---|---|
| 클링커 생산 | 기간 내 하루 생산량(원료 투입량 × 24 ÷ 1.55)의 평균 t/d. DCS 일평균이 있으면 DCS, 없으면 가상 |
| 킬른 가동률 | (달력시간 − 정지시간) ÷ 달력시간. 장기 가동 중단 호기는 공장 평균에서 제외. DCS 없으면 가상 |
| f-CaO | QMS 클링커 호기별 일평균의 기간 평균(공장은 설계용량 가중), 관리기준 0.7~1.7% 이탈 횟수 |
| 1종·3종 출하 | 기간 내 출하 로트(채취일 기준) 값의 평균, 로트 수와 KS 미달 건수 |

- 원료밀·사일로 재고·금일 출하 등 설비 상태 카드는 '현재' 값입니다.
- 28일 강도는 채취 28일 뒤에 나오므로 당월 로트에는 아직 값이 없을 수 있습니다.

## 데이터 구성
| 구분 | 출처 | 비고 |
|---|---|---|
| **분석값** (원료 XRF·LSF·SM·IM·잔사, 클링커 XRF·f-CaO, 시멘트 Blaine·45㎛·SO₃, 출하 시멘트 물성·강도, 인수검사) | **QMS 통합 업로드 양식** (`업로드양식.xlsx`, LIMS 원본 형식) | 화면에 기본으로 `Blue365_QMS.xlsx`(2025-01-01~2026-10-31)를 넣어 두었습니다 (`qms_default.json`) |
| **설비 운전값** (생산량·부하·온도·레벨·차량·로트) | 가상 | 양식의 ‘킬른’ 시트(DCS)를 채우면 킬른·예열기 운전값은 그 값으로 바뀝니다 |

- 분석 항목의 관리한계는 최근 90일 QMS 데이터의 **평균±3σ**로 자동 계산합니다(시멘트는 C/M·품종별). f-CaO는 사내 관리기준 **1.2 ± 0.5%(0.7~1.7%)**를 씁니다 (`src.html`의 `FCAO_TARGET`·`FCAO_TOL`).
- 최근 14일 시료가 없는 분석 항목은 ‘—’와 ‘마지막 시료 날짜’로 표시하고 상태 판정에서 뺍니다.
- C/M ‘현재 생산’은 시멘트 시트의 C/M별 마지막 시료(품명·투입사일로)이며, 경로표(`ROUTE`)와 다르면 ‘경로표와 다름’으로 표시합니다.
- 시멘트 시트의 Blaine·45㎛ 값이 LIMS 내려받기에서 서로 바뀌어 있으면(Blaine < 100, 45㎛ > 1000) 자동으로 바로잡습니다.
- 미래 날짜 행은 날짜 오류로 보고 제외합니다.

## 1단계 · 내 PC에서 QMS 파일 올리기
1. `cement_plant_3d.html`을 Edge 또는 Chrome으로 엽니다.
2. 오른쪽 위 **데이터** → QMS 통합 양식 엑셀(.xlsx)을 끌어다 놓습니다. 1만 행 이상 시트도 몇 초면 읽습니다.
3. 시트별 행 수, 분석 기간, 경고(보정·제외한 행)를 확인하고 **이 화면에 적용**을 누릅니다.
- 파일은 그 PC 브라우저 안에서만 읽고, 다음에 열 때도 유지됩니다(같은 PC·브라우저). **내장 기본 데이터로 돌아가기**로 되돌릴 수 있습니다.

## 2단계 · 팀 공유 (사내 PC 한 대를 서버로)
1. 그 PC에 **Python 3.8 이상**이 있으면 됩니다(추가 설치·인터넷 불필요).
2. `cement_plant_3d` 폴더를 복사하고 `서버실행.bat`(또는 `python server.py`)을 실행합니다. 처음 실행 시 Windows 방화벽에서 포트 8365를 허용하세요.
3. 팀원은 서버 창에 표시되는 **IP 주소**(예: `http://192.168.0.15:8365`)로 접속합니다. 컴퓨터 이름에 한글이 있으면 이름 주소는 동작하지 않습니다(브라우저가 `xn--…`로 바꿔 ‘잘못된 URL’이 뜸). IP는 `ipconfig`의 IPv4 주소로도 확인할 수 있고, 데이터 창에도 표시됩니다. 누군가 **팀에 공유하고 적용**을 누르면 모든 접속자 화면에 20초 안에 반영됩니다(서버에는 집계 결과만 저장).
4. `--watch "\\서버\품질\QMS"`를 붙이면 그 폴더에 저장된 최신 QMS 엑셀을 자동으로 반영합니다(매일 LIMS 내려받기 → 폴더 저장 운영).

| 서버 옵션 | 설명 |
|---|---|
| `--port 8365` | 포트 번호 |
| `--allow 대역` | 접속 허용 대역 (예: `192.168.10.0/24` 또는 `192.168.10.`, 쉼표로 여러 개). **지정하지 않아도 사내망 사설 IP(10.x, 172.16~31.x, 192.168.x)만 허용**하고 인터넷(공인 IP)에서 온 접속은 거절합니다 |
| `--allow-any` | 접속 대역 제한 끄기 (권장하지 않음) |
| `--key 암호` | (선택) 서버 공통 업로드 암호를 하나 더 겁니다. 기본은 ‘편집 권한 + 본인 비밀번호 재확인’ |
| `--watch 폴더` | 공유 폴더의 최신 `.xlsx` 자동 반영 (`--interval` 초, 기본 60) |
| `--history-mb 1024` | 이력(data/history) 최대 용량 MB. 넘으면 오래된 것부터 지움(최근 5개는 보관) |
| `--data 폴더` | 저장 위치 (기본 `data/`, 최근 200건 이력) |

- 기본으로 사내망 사설 IP에서 온 접속만 받고, **로그인한 승인 사용자만** 화면·데이터를 볼 수 있습니다.
- 연결은 HTTP(암호화 안 됨)입니다. 사내망 전용으로만 쓰세요.

### 로그인 · ID 등록 · 승인
1. **관리자 만들기 (처음 한 번)**: 서버 PC의 브라우저에서 `http://localhost:8365`로 접속하면 ‘관리자 계정 만들기’ 화면이 나옵니다. 다른 PC에서는 만들 수 없습니다.
2. **ID 등록**: 팀원이 처음 접속하면 ‘ID 등록’ 탭에서 부서·이름·아이디·비밀번호(영문+숫자 8자 이상)를 적어 요청합니다.
3. **승인**: 관리자가 오른쪽 위 사용자 아이콘(대기 건수 배지) → `/account`에서 요청을 보고 **편집** 또는 **뷰어**를 골라 승인하거나 거절합니다.
4. **권한**

| 권한 | 할 수 있는 일 |
|---|---|
| 뷰어 | 공정 화면·경영진 요약 보기, 업로드 양식 받기 |
| 편집 | 뷰어 + QMS 데이터 업로드 (올릴 때마다 본인 비밀번호 재입력) |
| 관리자 | 편집 + ID 승인·거절, 권한 변경, 사용 중지·재개, 비밀번호 초기화(임시 비밀번호 발급), 삭제, 기록 보기 |

- 세션은 12시간 유지(쿠키, HttpOnly·SameSite=Strict). 권한을 바꾸거나 사용 중지하면 그 사용자는 바로 로그아웃됩니다.
- 관리자가 비밀번호를 초기화하면 그 사용자는 임시 비밀번호로 로그인한 뒤 **새 비밀번호로 바꾸기 전까지 화면·데이터를 볼 수 없습니다.** 비밀번호를 바꾸면 다른 PC에 남은 로그인은 끊깁니다.
- 서버는 JSON 형식 요청만 받고, 보안 헤더(CSP)로 외부 주소 연결을 막습니다. 감사 기록(audit.log)에는 줄바꿈·탭이 들어가지 않게 정리해서 씁니다.
- 로그인 10회 실패 시 10분간 잠깁니다. 비밀번호는 PBKDF2-SHA256(20만 회, 사용자별 salt)으로만 저장됩니다.
- 사용자 목록은 `data/users.json`, 기록은 `data/audit.log`입니다. **`data/` 폴더를 주기적으로 백업**하세요. 관리자 비밀번호를 잊었다면 서버를 끄고 `users.json`에서 관리자 항목을 지운 뒤 다시 켜면 localhost에서 새로 만들 수 있습니다.
- `cement_plant_3d.html` 파일을 직접 열면(file://) 로그인 없이 내장 데이터로 열립니다. 이 파일은 서버 PC·공유 폴더에서 아무나 가져가지 못하게 보관하세요.
- 8365 포트를 공유기·방화벽에서 외부로 열지 마세요. Windows 방화벽은 ‘도메인/개인’ 네트워크만 허용하세요.

## 업로드 양식 (QMS 통합 양식 = LIMS 원본 형식)
`업로드양식.xlsx`는 현장 `Blue365_QMS.xlsx`와 같은 구조입니다: 1행 제목 · 2행 안내 · **3행 머리글(LIMS 이름 그대로)** · 4행 단위 · **5행부터 데이터**. 주황 머리글은 필수 칸입니다.

| 시트 | 내용 | 화면 |
|---|---|---|
| 원료(4~5-1호) · 원료(6~7호) | 원료밀 출구(R/M)·킬른 요입(K) 조합원료 XRF, 배합비 | 원료밀·원료 사일로(6-1~7-2)·킬른 요입 LSF |
| 원료 잔사 | 90㎛·200㎛ 잔사 | 원료밀 |
| 킬른 | DCS 시간 평균값 | 킬른·예열기 운전값 (비우면 가상) |
| 클링커(6K,7K) · 클링커(4K,5K) | 클링커 XRF·f-CaO·투입사일로 | 킬른 품질, f-CaO 관리도, 클링커 사일로 최근 투입 |
| 클링커일일 | XRD 광물상·크롬 | (데이터가 있으면 집계) |
