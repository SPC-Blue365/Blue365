# 시멘트 공정 3D 모니터링 (Blue365)

석회석 광산부터 출하까지 전체 공정을 3D 지도로 보여 주는 모니터링·경영진 보고 화면입니다.
공장 1곳, 킬른 5기(3·4·5·6·7호)를 기준으로 합니다. 공정 지도는 **탭**으로 나뉩니다.

| 탭 | 설비 |
|---|---|
| 전체 공장 | 모든 설비 + 석회석 광산·크러셔·프리블렌딩·품질관리실 |
| 3–5호 킬른 | 원료밀 3·4·5·5-1호 R/M, 원료 사일로 3·4·5호, 예열기 3·4·5호 P/H, 킬른 3·4·5호, 클링커 사일로 2·4·5호 |
| 6–7호 킬른 | 원료밀 6·7호 R/M, 원료 사일로 6-1·6-2·7-1·7-2호, 예열기 6·7호 P/H, 킬른 6·7호, 클링커 사일로 6-1~6-6호 (6-4·6-6호는 수출·3종 클링커 별도 관리) |
| 시멘트 밀·사일로 | 시멘트 밀 2~7호 C/M, 시멘트 사일로 1·2·5~11호, 4호 사일로(F/A 플라이애시), 출하장 |

시멘트 밀 경로: 2~6호 C/M은 모든 킬른 클링커, 7호 C/M은 6·7호 킬른 클링커만 사용합니다. 2~4호 C/M → 5~9호 사일로, 5호 C/M → 3종 1호·1종 2호, 6호 C/M → 1종 8호·S/C 2종 10호·S/C 3종 11호. 4호 사일로의 F/A는 혼합재로 시멘트 밀에 투입합니다.
2~4호 C/M의 생산 품종(현재 1종으로 추정)과 7호 C/M의 투입 사일로는 **확인 필요**로 표시합니다. 이 경로 정보는 `src.html`의 `ROUTE`에서 고칠 수 있습니다. C/M별 현재 생산 품종(`CUR`)은 가상 예시입니다.
호기별 설계 용량은 3호 2,500, 4호 2,549, 5호 2,678, 6호 7,100, 7호 7,100 t/d(합계 21,927 t/d)입니다. **3호는 가동 중단** 상태로 표시하며, 공장 합계 생산 목표·평균 f-CaO·모듈 평균·알람 판정에서 뺍니다(가동 4기 설계 19,427 t/d 기준).
호기별 클링커 생산은 원료 투입량 × 24 ÷ 원료/클링커 환산계수 **1.55**로 추정합니다.
용량·환산계수·가동 중단 설정을 바꾸려면 `src.html`의 `KILN_DEF`·`CLK_FACTOR`와 `make_template.py`의 `KILNS`·`STOPPED`·`CLK_FACTOR`를 고친 뒤 `build.py`, `make_template.py`를 다시 실행하세요.
업로드 데이터에서는 원료 투입량(feed)이 1 t/h 이하인 호기를 가동 중단으로 판단합니다. 투입량 값이 없으면 위 설정을 따릅니다.
처음에는 **시연용 가상 데이터**로 열리고, 엑셀을 올리면 실제 데이터로 바뀝니다.

## 파일
| 파일 | 용도 |
|---|---|
| `cement_plant_3d.html` | **사내망용 완성본.** 3D 라이브러리가 파일 안에 들어 있어 인터넷 없이 열립니다. |
| `업로드양식.xlsx` | 데이터 업로드 양식 (시트 5개 + 안내) |
| `server.py`, `서버실행.bat` | 팀 공유 서버 (파이썬 표준 라이브러리만 사용) |
| `src.html` | 편집용 원본 (3D 라이브러리를 CDN에서 불러옴) |
| `build.py` | `src.html` → `cement_plant_3d.html` 오프라인 빌드 |
| `make_template.py` | 업로드 양식 다시 만들기 (개발용, openpyxl 필요) |
| `vendor/three.min.js` | three.js r149 (MIT, `vendor/three.LICENSE`) |

## 1단계 · 내 PC에서 엑셀 올리기
1. `cement_plant_3d.html`과 `업로드양식.xlsx`를 같은 폴더에 둡니다.
2. `cement_plant_3d.html`을 Edge 또는 Chrome으로 엽니다.
3. 오른쪽 위 **데이터** 버튼을 누르고, 엑셀 파일을 끌어다 놓습니다(화면 아무 곳에 놓아도 됩니다).
4. 시트별로 몇 행을 읽었는지, 어떤 행을 왜 건너뛰었는지 확인한 뒤 **이 화면에 적용**을 누릅니다.

- 파일은 그 PC 브라우저 안에서만 읽고, 외부로 보내지 않습니다.
- 다음에 다시 열면 마지막으로 올린 데이터가 그대로 나옵니다. 브라우저 저장소를 쓰기 때문에 같은 PC, 같은 브라우저에서만 해당합니다.
- **가상 데이터로 돌아가기**를 누르면 처음 상태로 돌아갑니다.

## 2단계 · 팀 공유 (사내 PC 한 대를 서버로)
팀원 모두가 같은 데이터를 보려면, 항상 켜져 있는 사내 PC 한 대에서 서버를 실행합니다.

1. 그 PC에 **Python 3.8 이상**이 설치되어 있어야 합니다. 추가 패키지 설치나 인터넷 연결은 필요 없습니다.
2. `cement_plant_3d` 폴더를 통째로 그 PC에 복사합니다.
3. `서버실행.bat`을 더블클릭하거나 `python server.py`를 실행합니다.
4. 처음 실행하면 Windows 방화벽 허용 창이 뜹니다. **개인/도메인 네트워크**를 허용하세요(포트 8365).
5. 팀원은 브라우저에서 `http://그PC이름:8365`로 접속합니다. 실제 주소는 서버 창에 표시됩니다.
6. 누군가 **팀에 공유하고 적용**을 누르면, 접속한 모든 사람의 화면에 20초 안에 반영됩니다.

### 서버 옵션
| 옵션 | 설명 |
|---|---|
| `--port 8365` | 포트 번호 |
| `--key 비밀번호` | 업로드할 때 비밀번호를 요구합니다(영문·숫자). 조회는 비밀번호 없이 됩니다. |
| `--watch "\\서버\품질\업로드"` | 공유 폴더에 가장 최근 저장된 `.xlsx`를 자동으로 반영합니다(60초 간격). |
| `--interval 60` | 공유 폴더 확인 주기(초) |
| `--data 폴더` | 저장 위치. 기본값은 `data/`이며 `latest.json`과 최근 200건 이력을 둡니다. |

### 보안 관련 참고
- 서버는 HTTP로 동작하고 로그인 기능이 없습니다. **사내망 안에서만** 쓰고, 외부에서 접속할 수 있게 열지 마세요.
- 업로드를 제한하려면 `--key` 옵션을 쓰세요. 업로드 이력(올린 사람·시각·파일명)은 `data/history/`에 남습니다.

## 업로드 양식 (시트는 필요한 것만 채우면 됩니다)
| 시트 | 열 | 화면에서 쓰이는 곳 |
|---|---|---|
| 공정값 | 일시, 설비코드, 항목코드, 값 (항목명·단위는 참고용). 설비코드: RM-3·4·5·5-1·6·7 / RS-3·4·5·6-1·6-2·7-1·7-2 / PH-3~7 / KL-3~7 / CS-2·4·5·6-1~6-6 / CM-2~7 / SL-1·2·4(F/A)·5~11 | 설비 상세 패널, 추이 그래프, 알람 이력 |
| 클링커XRF | 일시, 호기(3호~7호), CaO, SiO2, Al2O3, Fe2O3, MgO, SO3, f-CaO | 호기별 LSF·SM·IM, Bogue 광물, f-CaO 관리도 |
| 시멘트품질 | 일시, 품종, Blaine, SO3, MgO, 강열감량, (3·7·28일강도) | KS L 5201 대비 판정, 28일 강도 KPI |
| 생산출하 | 일자, 클링커생산(공장 합계), 시멘트출하, 출하계획, (킬른가동률) | 생산 실적, 출하·사일로, KPI |
| 관리기준 | 설비코드, 항목코드, 하한, 상한 | 정상/주의/이탈 판정 기준 |

- 열 이름 뒤의 단위 표기 `(%)`, `(t)`나 띄어쓰기는 무시합니다. 시트 이름이 달라도 첫 줄 열 이름으로 시트 종류를 알아봅니다.
- 킬른 설비코드·호기는 `KL-5`, `5호`, `5호기` 어느 형식으로 적어도 됩니다.
- 일시는 엑셀 날짜 서식이나 `2026-11-10 09:00` 형식으로 넣습니다.
- `.xls`(예전 형식)는 읽을 수 없습니다. `.xlsx`로 다시 저장하거나 시트별 CSV로 올리세요. CSV는 UTF-8과 엑셀 기본 저장(CP949)을 모두 읽습니다.
- 값이 없는 항목은 화면에 `—`로 표시하고 상태 판정에서 뺍니다.
- 3D 지도의 트럭, 로트 추적, 시료 목록은 아직 가상 예시입니다.

## 기준값 출처와 주의
- KS 기준값은 KS L 5201(포틀랜드 시멘트) 1종 기준으로 적었습니다. **최신 개정판 원문과 대조한 뒤 사용**하세요. 특히 강열감량을 확인해야 합니다.
- 양식에 들어 있는 사내 관리기준과 28일 강도 예측식은 **예시값**입니다.
- LSF·SM·IM·C₃S 계산식은 일반적인 정의(Bogue 식)를 사용했습니다.
