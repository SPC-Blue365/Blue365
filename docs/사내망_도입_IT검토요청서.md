# Blue365 품질관리 시스템(QMS) — 사내망 도입 IT 검토 요청서

| 항목 | 내용 |
|---|---|
| 신청 부서 | 품질관리팀 |
| 신청 목적 | 품질 데이터 모니터링·분석·이상 알림용 **사내 자체 제작 프로그램**을 사내망 PC에서 사용 |
| 요청 사항 | 정식 절차에 따른 **반입·검토·설치(또는 소스 반입)** 허가 |
| 대상 PC | 품질관리팀 사내망 PC 1대(공유 실행 시 사내망 내 열람) |
| 버전 | v2026.10.11 · Windows 10/11 64비트 |

> 본 요청서는 품질관리팀이 사내에서 사용하기 위해 만든 분석 프로그램을 **회사 보안 절차를 지켜** 도입하기 위한 검토 요청입니다. 보안 정책을 우회하는 어떤 방법도 사용하지 않으며, IT 부서의 승인·방법에 따르겠습니다.

---

## 1. 프로그램 개요

- **용도**: 시멘트 품질시험 결과(원료·클링커·시멘트·물성)를 모니터링하고, 관리기준(KS·사내기준) 이탈 시 알림, 원인 분석·배합 설계·강도 예측을 제공하는 **내부 품질관리 도구**.
- **동작 방식**: 사내 PC에서 **로컬로 실행**되는 프로그램. 웹 브라우저(Edge·Chrome)로 `http://localhost:8501` 에 접속해 화면을 봅니다. **외부 서버·클라우드를 쓰지 않습니다.**
- **사용자**: 품질관리 담당자. (선택) 공유 실행 시 사내망 내 다른 PC·태블릿에서 열람.
- **소스 공개**: 전체 소스가 사내 GitHub 저장소 `spc-blue365/blue365` 에 있어 **IT가 직접 감사**할 수 있습니다.

## 2. 보안 프로파일 (검토 포인트)

| 항목 | 내용 |
|---|---|
| 설치 방식 | **무설치** — 폴더 압축 해제만. **관리자 권한 불필요, 레지스트리 변경 없음** |
| 실행 구성요소 | Python 3.13.16 (**python.org 공식 NuGet 배포본**, 게시자 Python Software Foundation, SHA-512 검증) + 표준 오픈소스 라이브러리 |
| 외부 통신 | **기본 없음** (사용통계 전송 끔, 오프라인 동작). 예외는 모두 **사용자가 직접 켤 때만**: ① AI 보고서(api.anthropic.com, 사내 보안 승인 후) ② 사용자가 설정하는 메일(SMTP)·메신저 웹훅·LIMS(DB·REST) |
| 네트워크 포트 | TCP 8501. `2_RUN.bat` 은 이 PC(127.0.0.1)만, `3_RUN_SHARE.bat` 실행 시에만 사내망 접속 수신 |
| 데이터 저장 | **전부 로컬** (설치 폴더\data, SQLite·JSON). 외부 전송 없음 |
| 설치 폴더 밖 변경 | (선택 기능 사용 시만) 작업 스케줄러 작업 1개, Windows 방화벽 규칙. 그 외 시스템 변경 없음 |
| 구성요소 명세 | 라이브러리 66종의 이름·버전·라이선스·파일 해시를 `components.xlsx` 로 제공(해시 고정 설치) |
| 디지털 서명 | Python 실행 파일(python.exe, pythonw.exe)은 Python Software Foundation 서명 |

## 3. IT 부서에 드리는 요청 (아래 중 가능한 방법으로)

**A. 승인된 반입 방법으로 파일 전달 + 화이트리스트** (가장 간단)
- 분할 ZIP 6개(총 약 152MB)를 회사가 허용하는 반입 경로(승인 전송 시스템·IT 직접 전달 등)로 받고, 아래 **SHA-256 해시**로 무결성 확인 후 실행 허용 등록.

**B. 사내 GitHub 채널로 소스 반입**
- 소스 전체가 `spc-blue365/blue365` 에 있습니다. 승인된 경로로 소스를 내려받고, 필요한 파이썬 구성요소는 **사내 PyPI 미러** 또는 승인 반입으로 설치. (인터넷 차단 환경이면 구성요소 묶음도 함께 반입 필요)

**C. IT 직접 설치 / 소프트웨어 센터 등록**
- IT가 검토 후 직접 설치하거나 사내 배포 채널에 등록.

> 어느 방법이든 좋습니다. **회사 표준 절차에 맞는 방법을 IT에서 지정**해 주시면 그에 맞춰 준비하겠습니다.

## 5. 후속 단계 — LIMS 연동 (설치 승인 이후)

설치가 승인된 뒤, 사내 LIMS의 **읽기 전용 계정**과 **결과 뷰(View)** 로 시험 결과를 자동으로 가져오려 합니다.
- LIMS DB 비밀번호·토큰은 **화면·소스에 저장하지 않고** 해당 PC의 보안 설정 파일에만 둡니다.
- 구체적 요청 항목(계정·뷰 정의·방화벽 등)은 별첨 **「LIMS 연동 준비서」**(docs/LIMS_연동_준비서.xlsx)에 정리되어 있습니다.

- 반입 방법·보안 조건을 알려주시면 그에 맞춰 패키지·문서를 준비하겠습니다.
