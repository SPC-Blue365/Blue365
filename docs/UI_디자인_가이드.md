# Blue365 UI 디자인 가이드 (모든 대시보드·앱 공통)

> 적용 범위: 이 사용자가 만드는 **모든 대시보드·웹앱·HTML 보고서**(Blue365 QMS뿐 아니라 이후 프로젝트 포함).
> 참고한 것: 사용자가 공유한 UI 용어 카드 12장(헷갈리는 UI 짝, 움직임 이름, 화면 전환, 완료 표현, 공유 아이콘, 평점 UI, 메뉴 버튼, 화면 이동, 행동 심리, 알려주는 방법, 기다리는 화면).
> 구현 예: `qms/viewer_template.html`(보는용 현황판, HTML), 관리용 Streamlit 앱 = `qms/theme.py`(THEME_CSS + KIT_CSS) + `qms/uikit.py`(같은 카드·제목 HTML 조각).

## 1. 한눈에 보는 스타일

| 요소 | 규칙 |
|---|---|
| 바탕 | 연회색 `#F2F4F6` (어두운 모드 `#101114`) |
| 카드 | 흰색, 모서리 **20px**, 테두리 없음, 아주 옅은 그림자 |
| 카드 안 미리보기(well) | 더 옅은 회색 `#F7F8FA`, 모서리 14px. 숫자·그림·상태 아이콘을 여기에 둔다 |
| 카드 제목 | `01` 파란 번호 + **굵은 한국어 제목** + 아래 회색 보조 설명(영문 용어나 단위·기간) |
| 강조색 | **파랑 한 색** `#3182F6`(옅은 바탕 `#E8F3FF`, 진한 글자 `#1B64DA`). 다른 색은 상태색으로만 쓴다 |
| 상태색 | 정상 `#0CA30C` · 주의/경고 `#FAB219` · 심각 `#EC835A` · 위험 `#D03B3B`. **색 + 글자**(칩)로 함께 표시. 색만으로 구분하지 않는다 |
| 화면 머리 | 알약 꼬리표(옅은 파랑) → **큰 두 줄 제목**(800 굵기), 핵심 단어만 파랑 → 회색 한 줄 설명 |
| 제목 말투 | 결론을 말로 쓴다. 예: "조치가 필요한 알림이 **4건** 있어요", "1종 28일 강도, **미리** 알아봐요" |
| 글꼴 | Pretendard → 맑은 고딕 → Apple SD Gothic Neo. 숫자는 `tabular-nums`(자릿수 정렬) |
| 배치 | 카드 바둑판(넓으면 3~4칸, 휴대폰 1칸), 칸 사이 14px, 가로 스크롤 없음, 휴대폰 좌우 여백 16px |
| 어두운 모드 | 같은 구조. 색은 어두운 모드용으로 따로 지정한다(자동 반전 금지) |

## 2. 헷갈리는 짝 — 상황별로 무엇을 쓰나

| 상황 | 쓰는 것 | 쓰지 않는 것 / 이유 |
|---|---|---|
| 켜고 끄면 바로 적용 | 토글 | 체크박스(저장 버튼을 눌러야 적용될 때만) |
| 여러 개 중 **하나** | 라디오 / 짧으면 **세그먼트**(2~5개: 품종, 재령 1·3·7·28일, 일·주·월) | 6개 이상이면 칩·드롭다운 |
| 여러 개 **함께** 고르기 | 체크박스 / **칩(거르기)** — 선택 시 ✓ + 파란 테두리 | |
| 화면 자체를 바꿈 | **탭**(넓은 화면: 위쪽 밑줄 탭 / 휴대폰: **하단 탭바**) | 같은 자료를 다른 보기로만 바꿀 땐 세그먼트 |
| 짧은 확인 | **토스트**("링크를 복사했어요", 2초) | 되돌리기가 필요하면 **스낵바**("삭제했어요 · 되돌리기") |
| 놓치면 안 되는 안내 | **배너**(맨 위, 닫기 ×) — 예: "원료 자료가 3일째 들어오지 않았어요" | |
| 결정이 필요 | **모달**(넓은 화면) / **바텀시트**(휴대폰) — 버튼 2개: [닫기] [주 행동] | |
| 입력 실수 | **인라인 오류**(칸 아래 빨간 글씨 + 빨간 테두리) | 경고창 금지 |
| 용어 설명 | **툴팁**(ⓘ 누르면 짧은 설명: Cpk, RMSE, R², 95% 구간) | 긴 설명·버튼이 필요하면 팝오버 |
| 개수 알림 | **배지**(빨간 숫자, 예: 원인 진단 탭에 위험·경고 수) | 분류·속성은 칩 |
| 처음 쓰는 사람 안내 | **코치마크**(처음 한 번, "알겠어요") | 매번 띄우지 않는다 |
| 이동 | **버튼**(행동: 적용·저장) vs **링크**(다른 화면 보기) | |
| 입력 칸 이름 | **라벨**(칸 위에 항상 보임) | 자리표시자(placeholder)만으로 이름 대신하지 않음 |
| 메뉴 | 햄버거 ≡(전체 메뉴) · 케밥 ⋮(이 항목 더 보기) · 미트볼 ⋯(가로 공간) · 슬라이더(거르기 설정) | |
| 목록 형태 | **카드**(한눈에 비교·그림 있음) vs **리스트**(많은 행·빠른 훑기, 오른쪽 › ) | |
| 빈 자료 | **빈 화면**: 회색 원 + "아직 자료가 없어요" + 다음에 할 일 한 줄 | "No data" 금지 |

## 3. 기다리는 화면 · 완료 표현

| 상황 | 쓰는 것 |
|---|---|
| 1초 미만 | 아무것도 표시 안 함 |
| 1~3초, 화면 모양을 안다 | **스켈레톤**(회색 자리) |
| 짧고 모양을 모른다 | **스피너** |
| 진행률을 안다(업로드·분석) | **진행 바** / **진행 링**(KS 적합률처럼 비율 자체가 정보일 때도 링) |
| 여러 단계 | **단계 표시(스테퍼)** — 예: 원인 진단 5단계, 자료 반영 3단계 |
| 버튼 누른 뒤 처리 중 | **로딩 버튼**(버튼 안에서 돌고, 두 번 누르기 막음) → 끝나면 "저장됐어요" |
| 완료 | 체크 그리기 · 진행 100% · 토스트. 큰 작업(자료 적용)은 **완료 화면**(몇 행 반영, 다음 할 일 버튼) |

## 4. 움직임(애니메이션) 규칙

| 용도 | 움직임 | 값 |
|---|---|---|
| 들어오는 요소 | **이즈 아웃**(처음 빠르고 끝에서 느리게) | `cubic-bezier(.2,.8,.2,1)`, 200~340ms |
| 카드 여러 개 | **순차 등장(stagger)** | 카드마다 35ms 간격 |
| 탭 바꿈 | **페이드 스루** | 260ms |
| 선택·누름 반응 | **스프링**(살짝 넘쳤다 멈춤) | `cubic-bezier(.34,1.56,.64,1)` |
| 휴대폰 시트 | 아래에서 **슬라이드** | 320ms |
| 금지 | 바운스·컨페티는 업무 화면에 쓰지 않는다 | |
| 접근성 | `prefers-reduced-motion`이면 **모든 움직임 끔** | |

## 5. 화면 이동(내비게이션)

- 넓은 화면: **고정 헤더**(스크롤해도 위에 남음, 반투명) + 상단 밑줄 탭.
- 휴대폰(720px 이하): **하단 탭바**(아이콘 + 짧은 이름, 배지).
- 다른 화면에서 넘어왔으면 **브레드크럼 + 뒤로 가기**(예: "‹ 종합 현황 › 원인 진단").
- 긴 화면은 **맨 위로 버튼**(플로팅, 스크롤 600px 이후 등장).
- 화면 주소에 탭을 남긴다(`#diagnosis`) → 링크로 바로 그 화면을 공유할 수 있다.
- **공유 버튼**: 휴대폰은 기기 공유 시트, PC는 링크 복사 + 토스트("링크를 복사했어요" / 공유 드라이브 파일이면 "파일 위치를 복사했어요").

## 6. 숫자·평가 표시

- 핵심 숫자는 **큰 숫자 카드**(30px 굵게 + 작은 단위) + 오른쪽 위 상태 칩.
- 분포·건수는 **평점 요약형**: 왼쪽 큰 총합, 오른쪽 항목별 막대(위험·경고·주의).
- 예측값은 **범위 바**: 95% 구간(옅은 파랑) + 예측점 + KS 하한(빨강)·사내 하한(주황) 표시선.
- 그래프: 선 2px, 마지막 점 강조, 관리기준은 옅은 파란 띠, KS는 빨간 선, 눈금 하나(이중 축 금지), 마우스를 올리면 값 툴팁.
- 추정치는 반드시 "추정"이라고 쓴다.

## 7. 행동 심리 — 업무 화면에서 쓰는 범위

| 원리 | 쓰는 방법 | 쓰지 않는 방법 |
|---|---|---|
| 기본값 효과 | 권장 설정을 기본 선택 + "추천" 칩 | 불리한 선택을 몰래 기본값으로 |
| 프레이밍 | 결론을 말로: "30로트 중 30로트 적합" | 숫자를 유리하게만 보이게 |
| 앵커링 | 기준선(KS·사내 기준)을 항상 함께 표시 | |
| 자이가르닉 효과 | 미완료 작업 진행률("관리기준 12개 중 8개 입력") | |
| 피크엔드 | 큰 작업 끝에 명확한 완료 화면 | |
| 선택 과부하 | 선택지가 많으면 분류 칩 → 목록 2단계 | |
| 희소성·손실 회피 | **사용하지 않음**(사내 품질 도구에 부적합) | 가짜 마감·재고 압박 |

## 8. 만들 때 점검표

- [ ] 화면 머리 = 알약 꼬리표 + 결론형 두 줄 제목(핵심 단어만 파랑) + 회색 설명
- [ ] 카드 = 흰색 20px + 회색 미리보기 + `01 제목 / 보조 설명`
- [ ] 강조색은 파랑 하나, 상태는 색 + 글자 칩
- [ ] 선택지 2~5개는 세그먼트, 거르기는 칩, 화면 전환은 탭(휴대폰은 하단 탭바)
- [ ] 빈 화면·오류·완료 문구가 "~해요"체로 다음 할 일을 알려 준다
- [ ] 용어는 ⓘ 툴팁, 놓치면 안 되는 안내는 배너, 짧은 확인은 토스트
- [ ] 이즈 아웃·순차 등장, 움직임 줄이기 설정 존중
- [ ] 390px 휴대폰에서 가로 스크롤 없음, 어두운 모드 확인
- [ ] 인터넷 없는 사내망에서 열리는지(외부 글꼴·스크립트 없이)

## 9. Streamlit 앱에서 같은 모양 만들기(구현 메모)

| 보는용 현황판 | Streamlit(관리용) |
|---|---|
| 화면 머리(꼬리표 + 결론형 제목) | `page_header(ctx, 제목, headline="…\n**강조**…")` — 기본 문구는 `qms/ui.py` HEADLINES |
| 카드 바둑판 | `uikit.grid([uikit.kpi_card(...), uikit.card(...)])` |
| 흰 카드 | `st.container(border=True)` → 자동으로 `qms_card_N` 키가 붙어 흰 카드(그림자·20px) |
| 숫자 카드 | `st.metric` → CSS로 위 회색 미리보기(값) + 아래 `01 제목` |
| 세그먼트 / 칩 | `st.segmented_control` / `st.pills` (가로 `st.radio`도 세그먼트 모양) |
| 배너 / 빈 화면 / 섹션 제목 | `uikit.banner()`, `uikit.empty()`, `uikit.section()` |
| 알림 목록 | `st.container(key="qms_li_N")` 안에 내용 + "진단 ›" 버튼 |
| 그래프 | 배경 투명(흰 카드 위에 바로) — `plotly_chart` 래퍼가 자동 처리 |
