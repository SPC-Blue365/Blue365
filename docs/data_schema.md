## 2. 핵심 컬럼

### ① 광산 (Mine)
- `채굴일자`(date), `채굴시간(교대)`[1·2·3차] 또는 `시작시간`/`종료시간`
- `공정구분` = **기존 / 신설 / 운휴** (라인 구분) ✅
- `OSP적재구역` = 채굴물을 적재한 품위 구역코드 ✅ (복합코드 존재: "50/55", "55-45", "100-0" 등 → 한 교대에 여러 구역 적재)
- `CaO품위`, `MgO품위`(%), `이송물량(톤)` (49Q는 object형+'-' 혼입 → 정제 필요)

### ② OSP (인출)
- `일자`(date), `인출시간`(time)
- `공정구분`: 기존시트=전부 '기존' ✅ / 신설시트=전부 NaN(시트명으로 '신설' 보정 필요)
- `P/W1호~P/W4호` = **인출 품위 구역코드**로 추정(값 20~95, 광산 OSP적재구역과 동일 어휘) ❓
  - 기존라인 → P/W1·2호 사용 / 신설라인 → P/W3·4호 사용 ✅ (구조적 분리 확인)
- `인출량`(톤) = 그 인출 회차 총량 ✅ (구역별 배분 규칙 ❓)

### ③ 야드 (Yard)
- `일자`, `시간`, `CaO`, `MgO`(%), `적재물량` (CNA=TPH / 45Q=B/S, 단위 상이 ❓)
- `Yard` 컬럼: 두 시트 모두 전부 결측 → 미사용/플레이스홀더

## 3. Join Key (식별자) — 후보 ✅ / 규칙 ❓

| 축 | Key | 근거 |
|----|-----|------|
| 라인 | `공정구분` (기존/신설) | 광산·OSP 모두 존재, 인출 P/W 분리와 일치 |
| 시간 | 일자 + 시각 | 광산(교대/구간) → OSP(인출시각) → 야드(2분연속) |
| 공간(품위) | `OSP적재구역` ↔ `P/W호` | 동일 구역코드 어휘(20~95) 공유 |

## 4. Time-Lag 규칙 ❓

- 광산(일/교대) → OSP(인출시각) → 야드(연속). 인출시각 ~ CNA 적재시각 사이의 지연 규칙 미확정.
- **확인 필요**: 인출→야드 적재 소요시간(분/시간), 상수 여부.

## 5. 목표 & 제약 + ⭐️핵심 발견

- **목표**: 야드 적재 CaO 평균 44.6%, std ≤ 0.5
- **CaO 실측 통계**:
  | 소스 | n | 평균 | std | min | max |
  |------|---|------|-----|-----|-----|
  | 49Q광산 | 141 | 46.09 | 2.96 | 38.7 | 51.9 |
  | 47Q광산 | 59 | 45.56 | 0.46 | 43.9 | 46.7 |
  | **CNA야드(최종)** | 20,952 | **44.67** | **1.85** | 25.0 | 54.2 |
  | 45Q야드 | 3,839 | 45.40 | 2.26 | 38.4 | 53.0 |
- ⭐️ **야드 CNA 평균(44.67)은 이미 목표(44.6)에 근접 — 진짜 문제는 '분산(std 1.85)'을 0.5로 줄이는 것.**
  → ML 목표는 평균 이동이 아니라 **변동성 제어(안정화)** 에 초점.
- CNA min 25.0 = 센서 드롭아웃/이상치 가능성 → 검증 게이트 점검 대상.
