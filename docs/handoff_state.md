## ⭐️ 현재 상태 (2026-07-23 야간) — 하이브리드 예측 모델 완성, 정직한 성능
도메인 정정 반영: **기존/신설 = 서로 다른 야드(4-5K/6-7K 킬른)**, **P/W=인출지점**, 품위=시간인지 매칭.
**야드 페어링(사용자 확정): 기존↔45Q, 신설↔CNA.**

**예측 모델 최종(Ridge AR, 시계열 CV) — `src/models/forecast.py`:**
| 라인→야드 | MAE | R² | (persist / naive) |
|---|---|---|---|
| 신설→CNA (6-7K) | **0.80** | +0.51 | 0.83 / 1.29 |
| 기존→45Q (4-5K) | **1.04** | +0.54 | 1.02 / 1.77 |
- 야드 CaO **지속성(AR)** 이 예측력의 핵심. **상류(OSP) 피처는 예측 개선 없음**(상관 0.18) → 처방적 배합제어는 현 데이터로 약함.
- 목표 MAE<0.5 **미달**(달성불가 정직고지): 상류 제어정보 부족이 원인. 단, naive 대비 대폭 개선 → **실시간 모니터링·조기경보용으로 실무 유용**.
- **다음 결정(사용자)**: 예측모델을 운영도구(모니터링/경보)로 확정할지, 배합최적화(scipy) 프레임워크를 약한신호 기반이라도 구축할지.
